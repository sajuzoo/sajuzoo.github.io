# 내 사주 동물 🦁

> 태어난 날에 동물이 숨어 있어

생년월일시를 넣으면 사주팔자를 계산하고, 일간(나를 뜻하는 글자)에 따라 열 마리 동물 중 하나를 찾아주는 웹앱. 사주를 몰라도 읽을 수 있게 모든 용어를 쉬운 말로 풀었고, 밤하늘 스티커북 느낌의 귀여운 룩으로 만들었다.

**바로 써보기 → https://sajuzoo.github.io/**

<br>

## 뭐가 나오나

| 기능 | 설명 |
|---|---|
| 내 동물 | 일간 10종 → 기린·다람쥐·강아지·고양이·곰·카피바라·아기 사자·고슴도치·아기 고래·수달 |
| 사주팔자 | 네 기둥 여덟 글자. 기둥을 누르면 "이 자리는 어린 시절 내 주변"처럼 쉬운 설명 |
| 다섯 기운 | 오행의 힘(%). 글자 수가 아니라 통근(뿌리)과 계절을 반영한 세기 |
| 더 자세히 | 성격 설명서, 일·사랑·돈·관계, 부족한 기운 채우는 법, 어울리는 동네, 올해 흐름 |
| 궁합 | 초대 링크 → 친구가 생일 입력 → 두 동물 궁합 카드 → 결과 되돌려 보내기. 서버 없이 링크 왕복으로 동작 |
| 잠금 | 상세 풀이는 보상형 광고 또는 공유로 열림 (지금은 모의 광고) |

<br>

## 계산은 믿을 수 있나

사주 앱에서 제일 중요한 건 만세력이 틀리지 않는 것. 그래서 검증에 공을 들였다.

- **24절기 시각 (1900~2100)**: 서로 다른 두 천문 알고리즘(6tail lunar, Meeus/VSOP87)으로 독립 계산해 4,824건 전부 1분 이내 일치. 한국천문연구원 공개값과도 대조.
- **한국 표준시 이력**: 1908년 이전 지방시, 1954~61년 +8:30, 서머타임(1948~60, 1987~88)을 tz 데이터베이스 기준으로 자동 보정.
- **팔자 계산**: 검증된 라이브러리(lunar_python)와 11,030건 교차 검증, 불일치 0건. 절입 ±1초, 자시 경계, 야자시 옵션 포함.
- **JS 엔진**: Python 엔진과 9,000건 대조, 불일치 0건.
- **오행 세기**: 천간은 지지에 뿌리(통근)가 없으면 30%만 인정, 지지 1.5배, 월지 계절 가중(왕상휴수사). 기존 만세력 사이트 분포와 맞춤.

옵션: 출생지 경도 보정(기본 켬, 서울 −32분), 야자시, 시간 모름.

## 구조

브라우저에서 전부 계산한다. 서버 없음, 비용 없음.

```
index.html              ← 배포되는 것. 엔진 + 데이터 + 화면이 한 파일
```

개발용 소스 (이 저장소엔 결과물만 있음):

```
saju_engine.py           Python 기준 엔진 (시간 보정, 네 기둥, 오행, 십신)
saju.js                  JS 엔진 (Python과 동일 로직)
data.js                  절기 테이블(절 12개×201년) + 표준시 전환 29건
readings.py              풀이 템플릿 (성격, 영역별, 개운법, 동네, 올해)
standalone_template.html 화면 템플릿
build_standalone.py      위를 합쳐 index.html 생성
gen_solar_terms.py       절기 테이블 생성 + 교차 검증
test_cross_check.py      lunar_python 대조 테스트
test_js.mjs              JS ↔ Python 대조 테스트
```

<br>

## 데이터 출처

- 절기·만세력: 한국천문연구원 공공데이터(검증용), lunar_python / pymeeus(계산)
- 표준시 이력: IANA tz database (Asia/Seoul)
- 동네 이름 한자: 서울특별시 자치구 안내 페이지의 행정동 목록
